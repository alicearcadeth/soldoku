## Release Signing

The keystore stays outside this repository. Pass it with Gradle properties or environment variables. See `docs/PRIVATE_SETUP.md`.

- Keystore path: `SOLANA_MOBILE_KEYSTORE_PATH`
- Key alias: `SOLANA_MOBILE_KEYSTORE_ALIAS` (the shell template recorded alias `android`; the submitted APK was signed with alias `sudoku-release`)
- Store password: `SOLANA_MOBILE_KEYSTORE_PASSWORD`
- Key password: `SOLANA_MOBILE_KEY_PASSWORD`

Do not put the keystore path, the password file, or the password values in this repository.
