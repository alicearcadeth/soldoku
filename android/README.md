## Build

```bash
solana-mobile webshell build .
adb install -r app/build/outputs/apk/release/app-release.apk
```

Without the matching release keystore, `gradlew assembleRelease` writes `app/build/outputs/apk/release/app-release-unsigned.apk`. That file is not a signed replacement for the submitted APK. With `~/.config/solana/sudoku-android.keystore` and alias `android`, the signed output is `app/build/outputs/apk/release/app-release.apk`. Pass the path and alias as Gradle properties. Passwords may come from the environment.

## Release Signing

The keystore stays outside this repository. Pass it with Gradle properties or environment variables. See `docs/PRIVATE_SETUP.md`.

- Keystore path: `SOLANA_MOBILE_KEYSTORE_PATH`
- Key alias: `SOLANA_MOBILE_KEYSTORE_ALIAS` (alias `android` in `sudoku-android.keystore`. The submitted certificate is in `docs/CURRENT_RELEASE.md`. The local `sudoku-release.keystore` does not match it.)
- Store password: `SOLANA_MOBILE_KEYSTORE_PASSWORD`
- Key password: `SOLANA_MOBILE_KEY_PASSWORD`

Do not put the keystore path, the password file, or the password values in this repository.
