## IF PORTING AN EXISTING APPLICATION TO MOBILE
Use this field if the form treats the web app to Android shell as a port:

We brought Soldoku's Sudoku and competition experience to Android and integrated Mobile Wallet Adapter with Seed Vault on a physical Seeker. The work includes wallet connection, message-based competition identity, wallet-signed escrow entry and claims/refunds, background/return handling, and saved-transaction recovery without clearing storage. We verified physical deposits, gameplay, scheduled settlement, winner payout and refunds on Solana Devnet. The mobile interface supports custom stake amounts, pause/resume, and clear wallet prompts. Our Android app is a hosted web shell; we do not claim a fully native game.

## IF THIS IS A NEW MOBILE APPLICATION
Use this alternative only if that classification applies; do not fill both fields unnecessarily:

Soldoku was built within the last three months as a mobile-first Sudoku game with Classic, Practice races and leaderboard competitions. We developed an Android shell, Mobile Wallet Adapter/Seed Vault handoff, message authorization and Solana escrow deposits, settlement, claims and refunds. Physical Seeker tests cover signing, wallet return, background persistence, cancellation and transaction recovery. The game and result verification run in our web app and Worker backend; stakes and payouts are on-chain. It is a working Devnet beta rather than a Mainnet or store launch.
