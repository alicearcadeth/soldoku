# External-player pilot guide (Devnet)

Short handout for a **small** invite-only pilot. Full plan: `FREE-COMPETITION-PILOT.md`.

TEST tokens have **no cash value**. Funded entry is **paused**. Card execution is **disabled**. Mainnet is **off**.

## Access

1. Install the Soldoku Android APK provided by the owner (package `com.sudoku.game`), **or** open `https://soldoku.com/` in a mobile browser.
2. Confirm the home screen shows **DEVNET · TEST TOKENS · NO CASH VALUE**.

## Modes

| Mode | Wallet? | What happens |
|------|---------|--------------|
| **Classic** | No | Solo puzzle on this device. Pause anytime. |
| **Practice** | No | Free two-player race (same grid). |
| **Compete (free)** | Yes — message sign | Join with a wallet **message** (not a deposit). Press **Start challenge** to begin your one timed attempt. |

## Free competition steps

1. Home → **Compete**.
2. Browse rooms or enter an 8-character room code → open the room. Confirm stake **0**.
3. **Join room** → approve the Soldoku identity **message** in your wallet / Seed Vault (Devnet). Cancel returns you to the app; try Join again.
4. **Start challenge** begins the timer. Leaving the app does **not** stop the competition timer.
5. Finish the grid. Your time and rank appear on the room leaderboard (ranks can change until the room ends).
6. Share only the **room code** the owner gave you — do not invite others unless the owner asks.

## Creating a free room (owner / invited creators)

Compete → **Create competition** → **Free competition** → set name/difficulty/period → pass the slider check → **Create room** → share the code privately.

## Timing and results

- One attempt per wallet per room.
- Fastest **correct** completion ranks; the server checks finishes.
- When the room ends, the leaderboard freezes.
- Automated solving and coordinated play are known limitations — this pilot does not claim solver resistance.

## Recovery

- Background / reopen: return via the app icon; use **Continue challenge** if you left the board.
- Wallet cancel: Close/Cancel/Back on the wallet sheet, then retry the action.
- Problems: use `FEEDBACK-TEMPLATE.md`. Do **not** send seed phrases or screenshots of Seed Vault passcodes.

## Out of scope

- Paying with a card  
- Mainnet  
- Depositing TEST into funded rooms (paused)
